# 使用指南

本文说明 OMTP 面板的各项功能。安装步骤见 [README](../README.md#安装)。

## 打开面板

- 快捷键 `Alt+M`（可在设置中修改，见[设置项](#设置项)）
- 顶栏的 OMTP 按钮
- 欢迎页上的 OMTP 按钮
- 斜杠命令 `/omtp`

面板内的键盘操作：`↑` / `↓` 移动选中行，`Enter` 使用选中的模型，`F` 收藏或取消收藏，`Esc` 关闭面板。焦点在输入框时这些按键交给输入框。

## 面板结构

左栏列出服务商，中间是模型列表，右侧是选中模型的详情。顶部的标签页：

| 标签页 | 内容 |
|---|---|
| 全部 | 全部服务商与模型 |
| 收藏 | 已收藏的模型 |
| 最近 | 最近使用的模型 |
| 配置档案 | SillyTavern 的连接档案（需要启用 SillyTavern 自带的 Connection Manager 扩展） |
| 登录 | 填写密钥、OAuth 登录、添加自定义服务商 |
| 用量 | 服务商额度与 token 统计 |
| 关于 | 扩展与插件版本、数据来源 |

列表上方的筛选开关：

- **显示非主流供应商**：取消勾选后只显示一线实验室、主流平台与本地运行时。
- **显示供应商翻译名**：有官方中文名的服务商显示中文名。
- **仅显示有评分的模型**：只显示有 AA-PersonalityBench 数据的模型。

面板左下角显示当前版本与更新状态，见[更新检查](#更新检查)。

## 连接方式

每个模型带一个徽章，表示 OMTP 用什么方式让 SillyTavern 调用它：

| 徽章 | 含义 | 需要服务端插件 |
|---|---|---|
| 原生 | SillyTavern 自带该服务商且接受该模型 ID。OMTP 直接写入 SillyTavern 的原生设置 | 否 |
| 转换 | 目录中的别名或分站（如 `minimax-cn`），映射到 SillyTavern 的某个原生来源后同样直接写入 | 否 |
| OMTP | SillyTavern 无法直接调用，经本地网关转发 | 是 |
| 配置档案 | SillyTavern 的一个连接档案，应用它会切换整组连接设置 | 否 |

使用 OMTP 徽章的模型时，OMTP 会：

1. 记下当前 Custom OpenAI 来源的设置；
2. 把聊天补全来源设为 Custom，地址设为网关（默认 `http://127.0.0.1:4100/v1`），模型设为 `服务商/模型`，并附上网关令牌。

之后切回原生模型，或停用扩展，OMTP 会恢复第 1 步记下的设置。

原生方式写入的是 SillyTavern 自己的设置，卸载 OMTP 后仍然有效。

## 登录与密钥

在 **登录** 标签页中：

- **API 密钥**：填写后点击保存。已保存的密钥只显示掩码。被上游拒绝的密钥会单独标出，并显示末四位。
- **OAuth 授权码**：点击登录后在新标签页完成授权，浏览器回到本机回环地址时登录自动完成。如果浏览器无法访问本机回环地址（远程部署、浏览器代理未绕过 localhost、容器未发布回调端口），把授权完成后地址栏的 URL 粘贴回面板即可。
- **设备码**：面板显示验证码与验证地址，在任意设备上完成验证即可。
- **退出登录**：清除该服务商在 OMTP 中保存的凭据。

OMTP 按以下顺序查找凭据：OMTP 自己保存的凭据 → SillyTavern 中保存的密钥 → 环境变量（如 `OPENAI_API_KEY`）。所以在 SillyTavern 里填过的密钥不必重复填写。

部分服务商（如 opencode）在登录行上有 **将 User-Agent 伪装为 opencode 客户端** 开关，默认开启；关闭后网关转发 SillyTavern 自己的 User-Agent。

### 自定义服务商

**登录** 标签页底部的 **添加自定义服务商** 可以接入任意 OpenAI 兼容或其他受支持协议的接口：填写 ID、名称、适配器、Base URL、模型列表和密钥。自定义服务商会出现在面板和网关的模型列表中。

### 在线模型列表

服务商旁的刷新按钮会调用该服务商的模型列表接口，取回的模型带 **在线** 徽章。结果在 5 分钟内有效。获取失败时面板显示错误，并回到内置目录中的模型，不会继续显示旧列表。更换密钥、退出登录后，该服务商的在线列表会被清除。

## 收藏、最近与快捷槽位

- 在详情中点星标，或在列表中按 `F`，收藏模型。
- 使用过的模型自动进入 **最近**。
- 快捷槽位共 9 个，显示在面板顶部：
  - 在详情中点击 **保存到快捷栏**，再点击一个槽位；或按 `Alt+Shift+数字`，把当前使用的模型放进对应槽位。
  - 右键点击槽位清空它。
  - 在 SillyTavern 任意界面按 `Alt+1` … `Alt+9` 切换到槽位中的模型。

## 绑定

在详情中点击：

- **绑定当前聊天**：绑定保存在聊天的元数据里，随聊天文件保存。
- **绑定角色**：绑定保存在 OMTP 设置里。

打开聊天时，OMTP 先查聊天绑定，再查角色绑定；两者都有时以聊天绑定为准。绑定会同时恢复记录时的推理强度。设置中的 **自动应用聊天/角色绑定** 可以关闭此行为；已有的角色绑定在设置的 **绑定** 区域列出。

## 推理强度

支持推理的模型在详情中可以选择推理强度（`auto`、`min`、`low`、`medium`、`high`、`max`，以模型实际支持的档位为准）。强度按模型分别记住，切换回该模型时自动恢复，并写入 SillyTavern 的推理强度设置（`openai_reasoning_effort`）。

也可以用 `/effort`：不带参数时在可用档位间循环，带参数时直接设置（可用唯一前缀，如 `/effort hi`）。没有选中可用模型时，`/effort` 设置的是 SillyTavern 自己的推理强度。

## 附加请求体

详情中的 **编辑附加请求体** 可以给单个模型设置一段 JSON 对象，生成时合并到请求体中，例如：

```json
{ "top_k": 40 }
```

`model`、`messages`、`stream` 以及 API 路由相关的字段由 OMTP 管理，不能在这里覆盖；包含这些字段时会提示并移除它们。

## 配置档案

**配置档案** 标签页管理 SillyTavern Connection Manager 的连接档案：

- 从当前连接新建，或新建空白档案后逐项填写；
- 复制、改名、删除；
- 选择档案中记录哪些设置（API、服务器地址、模型、预设、密钥、模板等）；
- 使用档案、停止使用（切回 SillyTavern 的「None」），或用当前连接更新档案。

档案只保存连接设置，不影响聊天、角色和提示词。所有改动会同步到 SillyTavern 自己的档案下拉框。

## 用量与统计

- **用量** 标签页：已登录的订阅服务商显示额度窗口（如 5 小时、每周）的使用百分比、重置时间或账户余额；超过 70% 显示警告色，超过 90% 显示告警色。额度数据缓存 60 秒，可手动刷新。下方是本次会话与累计的 token 统计。
- **token 徽章**：API 抽屉工具栏中 OMTP 按钮旁边显示当前聊天的 token 数和估算费用，点击打开用量页。
- **统计页面**：`/omtp stats` 在本机启动统计页面（默认端口 3847）并在新标签页打开，显示每日用量、按模型和按聊天的费用。页面只监听本机，30 分钟无访问后自动关闭。

统计只覆盖经过网关的请求。费用按目录单价估算：输出 token 中包含推理 token；目录没有缓存单价时，缓存读写按输入单价计；在线发现、目录中没有单价的模型，按该服务商默认模型的单价（没有时取已定价模型的中位数）估算。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/omtp` | 打开面板 |
| `/omtp stats` | 启动并打开统计页面 |
| `/model [选择器]` | 切换模型并保存为默认。不带参数时打开面板 |
| `/switch [选择器]` | 只在本次会话中切换，不改默认模型。不带参数时打开键盘快速选择器 |
| `/effort [档位]` | 设置或循环推理强度 |
| `/usage` | 打开面板的用量页 |

`/model` 会覆盖 SillyTavern 自带的同名命令，并接受 `--quiet` 参数以兼容已有脚本。

选择器的常用写法：

| 写法 | 含义 |
|---|---|
| `anthropic/claude-opus-5-5` | 服务商/模型 ID，在第一个 `/` 处拆分 |
| `claude-opus` | 模型 ID 或关键词，模糊匹配 |
| `@1` … `@9` | 快捷槽位 |
| `@fav`、`@recent` | 第一个可用的收藏 / 最近模型 |
| `…:high` | 末尾加推理强度 |

完整语法见 [开发者 API](./developer.md#选择器语法)。

## 更新检查

面板左下角显示版本和更新状态。OMTP 读取所选通道在 GitHub 上的 `manifest.json`，比较版本号：

| 状态 | 含义 |
|---|---|
| 有更新可用 | 通道发布了更高的版本 |
| 已是最新 | 版本相同 |
| 本地版本较新 | 当前构建比通道新 |
| 更新检查失败 | 无法访问 GitHub，点击重试 |

点击状态会打开对应分支的提交页。结果缓存 10 分钟。Nightly 构建默认跟随 `nightly` 通道，其他构建默认跟随 `main`，可在设置中切换。

## 常见问题

**模型显示不可用，或按钮是灰的。** 详情会写明原因，常见的有：

- 没有凭据：在 **登录** 标签页填写密钥或登录。
- 没有安装服务端插件：OMTP 徽章的模型需要网关。
- 服务商只支持专有客户端协议（如 Cursor、GitHub Copilot 聊天），网关无法转发。这类服务商仍然列出，并注明原因。

**SillyTavern 原生的 API 选择器不见了。** OMTP 默认隐藏它。可以在 API 抽屉顶部点击 **显示原生 API 选择器**，或在设置中关闭 **隐藏原生 API 选择器**。

**目录里没有画图、语音、向量模型。** 目录只保留聊天模型。

**网关状态不是绿色。** 确认 `plugins/omtp` 存在、`config.yaml` 中 `enableServerPlugins: true`，并已重启 SillyTavern。端口 4100 被占用时网关会依次尝试 4101 … 4110；如果占用端口的是另一个 OMTP 网关，会直接复用它。

**OAuth 登录一直停在等待中。** 浏览器没能访问本机回调地址。把授权完成后地址栏中的完整 URL 粘贴到面板的输入框并提交。

**SillyTavern 1.12.7 – 1.16.x 上卸载后 Custom OpenAI 仍指向网关。** 这些版本不支持扩展的生命周期钩子，OMTP 通过轮询发现扩展被停用并恢复设置。如果直接删除了扩展文件，就没有代码能执行恢复，需要手动改回 Custom OpenAI 的地址。卸载前请先停用扩展。
